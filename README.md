## 📖 About

**Nexora** is a startup marketplace that bridges the gap between **creative professionals** and **clients**. The platform covers:

- 📷 **Photographers** - Wedding, Fashion, Portrait, Event
-  **Cinematographers** - Film, Documentary, Commercials  
- ✨ **VFX Artists** - 3D, Compositing, Motion Graphics
- 🎨 **Graphic Designers** - Branding, UI/UX, Print
- 📱 **Content Creators** - Video, Social Media, Strategy
- 📝 **Storytellers** - Scripts, Narratives, Brand Stories

---

##  Features

### 🎥 Hero Section
- **Realistic CSS Camera Lens** with 1080° scroll rotation
- **Camera flash effect** on scroll
- **Floating ad cards** with real product pricing (INR)
- GSAP animations with ScrollTrigger

###  Search & Filter
- Full-text search across names, roles, tags
- Filter by: Category, Budget (₹), Locality, Event Type
- Live result count updates
- Studio-based profiles (no artificial faces)

###  Portfolio System
- Work images as card headers
- Star ratings and project counts
- Skill tags and pricing in INR
- Detailed profile modals with portfolio samples

### 📊 Animated Stats
- Scroll-triggered number counters
- Indian number formatting (₹25,000)
- 4 key metrics display

###  For Creatives
- Floating metric cards
- Average earnings display (₹45,000/project)
- Transparent pricing model
- No hidden commission fees
